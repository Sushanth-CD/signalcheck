Easy to use with Powerful Features

Below are some of the theme features to help you better understand what we offer

Design Custom Property Cards & Pages

With the WPResidence theme, you can make your own property cards and pages. You can choose how they look, pick colors, and show the details you want. Add pictures, prices, and features to help people see what the home is like. This makes it easy for them to learn more.

Drag-and-Drop Elementor Widgets

With WPResidence, you can use drag-and-drop Elementor widgets to build your website. Just click, move, and place things where you want them. It’s easy and fun to use. You can add text, pictures, and more without needing to code. This helps you make a great-looking site fast.

Advanced Search Form Builder

With this real estate theme , you can use the Advanced Search Form Builder to help people find homes fast. You choose what to show, like price, rooms, or location. It’s easy to set up and looks nice on your site. This makes searching simple for everyone who visits your website.

Total Template Control: Design your own property & agent templates.

You can easily create any layout you need for property pages, agent profiles, or agency pages using the WPResidence Studio Template feature. This powerful tool lets you design custom headers, footers, and page templates. You can also assign each template to specific categories or tags, so your content is always shown the way you want.

Payments via WooCommerce, Stripe or Paypal

People can pay for real estate services using WooCommerce, Stripe, or PayPal. It’s safe, fast, and easy to use. Just choose the payment method you like best. This makes running your website simple and helps you get paid without any trouble.



Fast Loading Theme

The theme loads fast, so pages show up quickly for everyone. This makes your website easier to use and more fun to visit. People won’t have to wait, and they can find what they need right away. A faster site also helps you look more professional and get better results.

Video Presentation of WPResidence Real Estate Theme

Real Estate Api

WPResidence API helps developers build real estate websites on WordPress. They can easily add, edit, or delete property listings.

Mega Menu

The WPResidence Mega Menu helps developers build better menus for real estate websites –  they can create custom menus without writing any code.

Search That Delivers

The WPResidence Search Builder lets developers create custom search bars for real estate websites. Built with Elementor, it needs no coding.

Property Page Design

You can choose what to show on each property page. Turn parts on or off easily. Use tabs or accordion sections to keep things neat.

You can even make your custom property page layout with Elementor specific widgets and show homes the way you want. It’s easy and fun to make it just right.

Virtual Tour

Yelp Reviews

Flexibility and Variety

Easy and Powerful Property Search

WPResidence has a smart and easy search made for real estate sites. Add as many search fields as you want—like dropdowns, text, numbers, or dates. Choose which fields show for each property type and let users pick more than one option.

As people search, they see instant property suggestions with the Preview Results feature. They can also search by location and get live tips as they type. With Geo Location, users can find homes nearby, using miles or kilometers.

The search is fast and smooth with AJAX. Place the search bar above, below, or over the header. Users can save searches and get email alerts for new listings. You can also show prices in different currencies with a multi-currency widget.

Works on any device

WPResidence works on all devices like phones, tablets, and computers. The design changes to fit any screen, so your site always looks good.

MLS ready

Our theme works great with MLS and MLSImport.com. You can easily bring in MLS property listings to your site. Everything fits well with the theme and looks clean on all devices.

Wpresidence Studio

WPResidence comes with a large library of ready-made designs, making it easy to build your site fast. Just pick a style and start editing.

Complete Dashboard

Advanced Dashboard

The WPResidence dashboard is simple and powerful. Users can manage their profile, add or edit listings, save favorite homes, and get alerts for new properties. They can also message agents and keep track of chats.

Admins can control who registers, set up payments, and create membership plans. Everything is easy to use and all in one place.

Favorite Properties

Visitors can save their favorite homes. These show up in a list inside their user dashboard. From there, it’s easy to view or manage them anytime.

Save Search & Email Alert

Visitors can save their searches and get email alerts when new homes are added. They can also delete saved searches anytime from their user dashboard.

Instant Messages Inbox

Users can send private messages to agents and reply fast. All messages are saved in the user dashboard, so past coversations are easy to find.

Submit Properties

You can allow from end submissions, and fully manage the submit form fields and mandatory fields. Add your own custom fields and they sync with the front submission too.

Manage Properties

Your users can disable or enable a published property, delete a listing or edit it at any time. It’s also easy to find a specific properties using a dedicated search tool.

User Types

Admins can choose which user roles are active. When enabled, visitors can sign up as users, agents, developers, or agencies. Each role can be approved manually.

WooCommerce Payments

The theme works with the most popular payment gateways, Stripe, and Paypal. For those who wish to have Wire Transfer (offline payment), we support that as well.

Membership Submission

Admins can create membership plans for each user type. Each plan can include a set number of listings, featured properties, and a time limit in days, weeks, months, or years.

Paid Submission

Admins can let users pay per listing. Before posting a property, users must pay a fee. An extra fee can be added to make the property featured.

Built-in CRM for Lead Management

WPEstate CRM Included

The WPResidence theme includes a built-in CRM to help manage messages and contacts. When someone sends a message through a property or profile form, they’re saved as a contact. You can edit contacts, add notes, and manage leads from your dashboard.

Agents, agencies, and developers can also manage their own messages and leads. New contacts and messages can be added manually too. Everything is organized in one place, making it easy to keep track of people interested in your listings.

User Roles for Real Estate

Agent , Agency and Developers Roles​

WPResidence lets users sign up as agents, agencies, developers, or regular users. You choose which roles are allowed and can approve profiles before they go live.

Agencies and developers can add agents from their dashboard. Each role gets a custom profile page with info, reviews, and listings. You can show lists of agents or agencies by type or category.

All listings are shown with tabs, without reloading the page. Users can also connect their dashboard to HubSpot CRM for easy lead management.

Membership Control

When an agent adds a listing, it uses the membership plan bought by their agency or developer.

Custom Fields for Agent

When an agent is created you  add custom text fields to its profile. You will find the added information listed on the agent personal page.

User Type Pages

Each agent, agency, or developer has their own page. The design is unique for each type and shows all their info.

Reviews

You can enable / disable reviews for agent, agencies or developers. Users will be able to post a review and share their experience. Comments are automatically published or moderated by admin.

My Listings with Ajax

On the personal/company pages we list the properties using tabs and ajax technology. Now you can filter someone’s listings without having to reload the page.

CRM Integrations

Agencies, agents, and developers can manage their listings in the CRM dashboard. They can also connect to their HubSpot CRM using an API.

Compatibility

Compatible Plugins

WPResidence works with popular plugins like Elementor and WooCommerce for building and payments. It also supports IDX/MLS Import for adding MLS listings. With your theme license, you get three premium add-ons for free: Bakery Builder, Ultimate Addons, and Rev Slider.

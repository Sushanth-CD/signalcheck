### Cross-check of required conditions

None of the ten texts makes an explicit DA002 digital-arrest/remote-custody assertion, so DA002 is not expected for these cases. PH001 applies only to S020's request for a “verification code,” which is the unrecognized term discussed above; the other listed cases do not request a covered secret. PH011 is relevant to S017, S018, and S040; each contains a URL and a verification-related request, but the current account-threat and/or verification predicates miss the specific wording described above. The remaining DA001 examples contain pressure or authority intent, but the current implementation's supported phrase forms do not recognize their complete combinations.

No integration defect is evident in the inspected path: `analyze_content` combines text findings with URL findings, scoring deduplicates by rule ID, and `evaluate` predicts from whether any finding was returned. The reported misses are attributable to phrase coverage or scope/label alignment, not score aggregation. This is a code inspection conclusion, not a reproduced run.
